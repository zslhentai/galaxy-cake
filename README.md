# 星河生日蛋糕

[打开新版](https://zslhentai.github.io/galaxy-cake/) · [查看初版](https://zslhentai.github.io/galaxy-cake/original.html)

点击开屏后点燃蜡烛并循环播放背景音乐。拖动蛋糕旋转视角，滚轮或双指缩放，底部按钮可缩放和复位。

本地运行可在仓库根目录使用 `python3 -m http.server`。Blender 蛋糕工程位于 `starlight/Cake.blend`，运行 `blender -b -P starlight/adornments.py` 可重建新增糖艺网格。
